## 一、账号管理页改动

### 1.1 导入模板"角色"改"身份"

**改前：** 模板表头为 `姓名 / 手机号 / 身份证号 / 学院 / 班级 / 角色 / 子角色`，示例用英文 `student`。

**改后：** 表头改为 `姓名 / 手机号 / 身份证号 / 学院 / 身份`，示例用中文"学生"。

- "身份"列加了 Excel 数据验证下拉，选项：**学生、教师、企业导师、学院领导**
- 去掉"班级"列（后续再分配）
- 模板按钮"导入模板"改名为"下载批量添加模板"

### 1.2 批量导入适配中文身份

前端导入解析改为读 `row['身份']`，传 `identity` 中文值给后端。后端新增 `identityToRole()` 映射函数：

| 模板"身份"值 | role | subRole | refType |
|---|---|---|---|
| 学生 | student | null | student |
| 教师 | teacher | teacher | teacher |
| 企业导师 | teacher | mentor | teacher |
| 学院领导 | teacher | leader | teacher |

同时兼容旧英文值（student/teacher/mentor/leader），不破坏存量模板。

### 1.3 删除账号功能

- 后端新增 `DELETE /api/accounts/:id` 端点
  - 查出 users 表记录，获取 `ref_type` 和 `ref_id`
  - 若是学生，删除 `students` 表对应记录；若是教师，删除 `teachers` 表对应记录
  - 删除 `users` 表记录
  - 写审计日志
- 前端 API 新增 `deleteAccount(id)` 函数
- 账号列表每行操作栏新增"删除"按钮，点击后 confirm 确认再调用接口

## 四、后端改动

### 4.1 identityToRole 映射函数（`accounts.js`）

```js
function identityToRole(identity) {
  const value = normalizeText(identity) || '学生';
  const map = {
    '学生': { role: 'student', subRole: null, refType: 'student' },
    'student': { role: 'student', subRole: null, refType: 'student' },
    '教师': { role: 'teacher', subRole: 'teacher', refType: 'teacher' },
    'teacher': { role: 'teacher', subRole: 'teacher', refType: 'teacher' },
    '企业导师': { role: 'teacher', subRole: 'mentor', refType: 'teacher' },
    'mentor': { role: 'teacher', subRole: 'mentor', refType: 'teacher' },
    '学院领导': { role: 'teacher', subRole: 'leader', refType: 'teacher' },
    'leader': { role: 'teacher', subRole: 'leader', refType: 'teacher' },
  };
  return map[value] || map['学生'];
}
```

### 4.2 DELETE /api/accounts/:id 端点（`accounts.js`）

删除账号时同步清理关联的 students 或 teachers 表记录，写审计日志。

### 4.3 教师入库同步 phone/department（`accounts.js`）

**改前：** 教师创建账号时只往 `teachers` 表写 `name`，phone 和 department 丢失。

**改后：** 入库时按学院名查 `departments` 表得到 `department_id`，把 `phone` 和 `department_id` 一起写入 `teachers` 表：

```js
let deptId = null;
if (department) {
  const [deptRows] = await connection.query(
    'SELECT id FROM departments WHERE name = ? LIMIT 1',
    [department]
  );
  if (deptRows.length > 0) deptId = deptRows[0].id;
}
const [teacherResult] = await connection.query(
  `INSERT INTO teachers (name, phone, department_id) VALUES (?, ?, ?)`,
  [normalizedName, validatedPhone, deptId]
);
```

### 4.4 教师查询 JOIN users 兜底（`teachers.js` + `admin.js`）

**问题：** 之前已入库但没同步 phone 的老教师数据，在教师管理页看不到电话和学院。

**方案：** 教师列表查询和单个教师查询都 LEFT JOIN `users` 表，SQL 里分别查出 `teacher.phone` 和 `usr.account`（别名 `user_phone`），在 JavaScript 层做兜底：

```js
const fixedRows = rows.map((row) => ({
  ...row,
  phone: row.phone || row.user_phone || '',
  department_name: row.department_name || row.user_department || '',
}));
```

JOIN 条件用 `CONCAT(teacher.id)` 而非 `CAST(teacher.id AS CHAR)`，避免 `teachers` 表（`utf8mb4_unicode_ci`）与 `users` 表（默认 collation）之间的 collation 冲突。
